# Прополис · Здоровье

Локальная статическая версия информационного лендинга propolis-doctor.ru. Лендинг не принимает оплату, не собирает заявки через формы и должен переводить пользователя на GetCourse после предоставления заказчиком рабочей ссылки.

## Структура

- `index.html` — главная страница лендинга.
- `contacts.html` — контакты, реквизиты и отложенная Яндекс.Карта.
- `privacy.html` — черновик политики конфиденциальности.
- `terms.html` — черновик пользовательского соглашения.
- `medical-disclaimer.html` — медицинский дисклеймер.
- `offer.html`, `refund.html` — справочные черновики, закрыты от индексации.
- `thank-you.html` — техническая неиспользуемая страница, закрыта от индексации.
- `assets/css/` — стили.
- `assets/js/` — активные JS-файлы: меню, общая логика, cookie/map consent.
- `assets/images/`, `assets/icons/`, `assets/videos/` — медиа и иконки.
- `docs/` — документация для владельца и исполнителя.

## Как открыть локально

Запустить `start_site.bat` или выполнить `python serve_local.py`, затем открыть `http://127.0.0.1:8787/`. Локальный сервер нужен, чтобы URL вида `/contacts` открывались как соответствующие `.html`-страницы.

## Где менять данные

- GetCourse URL: заменить `#getcourse-link-required` в `index.html` на финальную ссылку.
- Маркетплейсы: заменить `#marketplace-link-required` после подтверждения ссылок заказчиком.
- Юридические тексты: `privacy.html`, `terms.html`, `medical-disclaimer.html`, `offer.html`, `refund.html`.
- Контакты и реквизиты: `contacts.html` и футеры страниц.
- Cookie и карта: `assets/js/cookie-consent.js`, стили в `assets/css/components.css`.

## Перед публикацией

- Получить финальную ссылку GetCourse.
- Утвердить юридические тексты у владельца/юриста.
- Проверить оферту, возвраты, ПДн, рекламное согласие, кассу и чек на GetCourse.
- Проверить, что нет аналитики, пикселей, форм заявок и скрытых внешних запросов.
- Проверить cookie-баннер и карту в сценариях accepted/necessary.
