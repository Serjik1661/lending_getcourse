# Project Structure

Проект является статическим сайтом без сборки.

- `index.html` — главная страница лендинга.
- `privacy.html`, `terms.html`, `offer.html`, `refund.html`, `medical-disclaimer.html`, `contacts.html` — юридические страницы.
- `thank-you.html` — demo-страница после отправки заявки.
- `assets/css/` — стили, разделенные на reset, переменные, базу, layout, компоненты, секции, формы, юридические страницы и адаптив.
- `assets/js/` — небольшие независимые модули: меню, форма, утилиты, инициализация.
- `assets/images/` — изображения по зонам сайта: hero, course, doctor, reviews, cta, og.
- `assets/icons/` — favicon, UI-иконки и социальные значки.
- `assets/fonts/` — локальные шрифты.
- `docs/` — документация для команды и публикации.
- `artifacts/` — только временные материалы разработки.
